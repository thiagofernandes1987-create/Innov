# Loop 1 — Arquitetura e governança

## Correções

- fonte única e precedência formalizadas;
- context map criado;
- catálogo de invariantes criado;
- SLOs definidos como metas, sem alegar medição;
- distinção entre `DESCRIBED`, `FORMALIZED`, `IMPLEMENTED`, `TESTED` e `INTEGRATED`.

## Auditoria

O V3 era conceitualmente forte, mas não ligava cada afirmação a enforcement e evidência. O loop reduz
a ambiguidade, porém não fecha runtime, IaC ou testes reais.
